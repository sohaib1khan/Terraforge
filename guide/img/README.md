# Guide screenshots

Drop PNG/JPEG/WebP files here. The how-to guide references them as `img/<name>.png`.

## Expected filenames

| Filename | What to capture |
|----------|-----------------|
| `01-sidebar.png` | Left sidebar / navigation |
| `02-setup.png` | First-run admin setup |
| `03-login.png` | Sign-in page |
| `04-dashboard.png` | Dashboard overview |
| `05-namespaces-list.png` | Namespaces list |
| `06-namespace-detail.png` | Open namespace (state + lifecycle) |
| `07-connect-dialog.png` | “Connect local Terraform” / curl dialog |
| `08-state-map.png` | State map with resources |
| `09-templates.png` | Templates page |
| `10-playground.png` | Playground session |
| `11-providers-docs.png` | Providers or Documentation |
| `12-settings-users.png` | Settings → users |

You can add extra shots (e.g. `08b-config-sync.png`) and link them from [`HOW_TO_USE.md`](../HOW_TO_USE.md).

## Tips

- Prefer a wide browser window so tables and sidebars aren’t crushed.
- Crop to the relevant panel when the full page is noisy.
- **Do not** commit screenshots that show live backend tokens, install codes, PATs, AWS keys, or passwords. Blur or regenerate those before capturing.
- Emails of demo accounts are fine; avoid production customer data.

After dropping files, open `HOW_TO_USE.md` on GitHub or locally in a Markdown preview — broken images usually mean a typo in the filename.
